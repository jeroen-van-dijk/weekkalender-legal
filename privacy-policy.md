## 2. Information Collection and Use

The Application collects limited technical information automatically when you install and use it, such as:

* Device IP address
* Operating system version
* App usage statistics (pages visited, time spent in the app)

This information is used only to:

* Maintain and improve the Application

The Application does **not** collect precise location data.

The Application does **not** require you to create an account or provide personal information to use its main features.
